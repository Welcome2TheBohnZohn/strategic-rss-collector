# Iran FM: Sustainable regional security requires collective responsibility

Published: 2026-10-28 00:00:00

Source: https://en.mfa.gov.ir/portal/newsview/796703

Iranian Foreign Minister Seyed Abbas Araghchi wrote in an Instagram post that the recent four-way meeting in Tehran with defense and security officials from Iran, Turkey, Saudi Arabia, and Pakistan provided a valuable opportunity to advance dialogue on regional peace and security and jointly address threats and challenges, stressing that sustainable security must be ensured through regional countries’ participation without military presence or intervention by extra-regional powers.
