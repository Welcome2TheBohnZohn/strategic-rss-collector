# China supports diplomacy on Iran nuclear issue, urges return to talks: Envoy

Published: 2026-11-25 16:23:52

Source: https://en.irna.ir/news/86332699/China-supports-diplomacy-on-Iran-nuclear-issue-urges-return

Tehran, IRNA – China’s ambassador to Tehran has reaffirmed Beijing’s support for a diplomatic solution to Iran’s nuclear issue, urging all sides to keep the door to negotiations open, de-escalate tensions, and return to dialogue.
