# Iran welcomes China’s call for new regional security architecture

Published: 2026-09-05 05:51:30

Source: https://en.irna.ir/news/86255033/Iran-welcomes-China-s-call-for-new-regional-security-architecture

Tehran, IRNA — Iran has welcomed Chinese President Xi Jinping’s recent emphasis on strengthening common security, saying regional countries should take control of their own future and build a homegrown security architecture.
