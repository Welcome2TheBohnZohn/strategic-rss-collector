# Washington’s security guarantees have proven ineffective: Security chief

Published: 2026-10-27 10:20:47

Source: https://en.irna.ir/news/86304921/Washington-s-security-guarantees-have-proven-ineffective-Security

Tehran, IRNA – Secretary of the Supreme National Security Council Major General Mohsen Rezaei says Washington’s inability to provide security guarantees has become evident, stressing that security in West Asia must be homegrown.
