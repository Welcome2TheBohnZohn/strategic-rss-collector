# Iran: Islamic holy sites must not be used as tool to incite sedition

Published: 2026-09-17 15:02:23

Source: https://en.irna.ir/news/86266834/Iran-Islamic-holy-sites-must-not-be-used-as-tool-to-incite-sedition

Tehran, IRNA — The Foreign Ministry spokesman has warned that Islamic holy sites must not be politicized and used as a tool to incite sedition and escalate regional tensions.
