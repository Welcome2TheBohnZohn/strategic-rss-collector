# Iran won’t allow enemy miscalculations to undermine its security, dignity: First VP

Published: 2026-11-04 15:54:22

Source: https://en.irna.ir/news/86312782/Iran-won-t-allow-enemy-miscalculations-to-undermine-its-security

Tehran, IRNA – Iran’s first Vice President Mohammad Reza Aref has reiterated that Iran will never allow the enemy’s miscalculations to undermine the country’s security and dignity.
