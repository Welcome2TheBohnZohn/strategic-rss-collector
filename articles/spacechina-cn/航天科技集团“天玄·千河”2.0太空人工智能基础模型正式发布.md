# 航天科技集团“天玄·千河”2.0太空人工智能基础模型正式发布

Published: 2026-09-09 00:00:00

Source: https://www.spacechina.com/n25/n2014789/n2014804/c4702521/content.html

9月4日，中国航天科技集团有限公司天玄大模型“观智”攻坚队成果路演暨攻坚总结会在杭州召开，正式发布“天玄·千河”2.0太空人工智能基础模型。
在“天玄·千河”1.0模型去年成功上注在轨星座、稳定运行的基础上，体系院、中国四维等单位在集团公司研发部组织下联合组建攻坚队，聚焦实战任务，高质量完成一系列关键工作，迭代形成“天玄·千河”2.0太空人工智能基础模型，圆满完成本轮阶段性攻坚目标任务。
“天玄·千河”2.0是我国自主可控、高分辨率、全球尺度的太空人工智能基础模型，形成了由地球基础模型、视觉基础模型及地球嵌入向量库组成的地球智能底座。其中，地球基础模型将复杂的地球信息提取为统一、稠密的语义特征，使地表状态与变化可量化、可检索、可预测；视觉基础模型深度融合多模态遥感数据，理解持续变化的地球系统。基于集团公司长期积累的多模态、多时相、跨尺度、广域覆盖的对地观测数据资源，该模型实现我国卫星遥感从“影像解译”到“认识地球”的范式跃升，更推动“算力上天、模型上星”的落地见效，是集团公司在抢占太空人工智能新赛道、培育智能原生新产业的重要阶段性成果。
（院宣）
