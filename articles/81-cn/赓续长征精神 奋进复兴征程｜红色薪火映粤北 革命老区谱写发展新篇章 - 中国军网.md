# 赓续长征精神 奋进复兴征程｜红色薪火映粤北 革命老区谱写发展新篇章 - 中国军网

央视网消息：广东是中央红军长征离开中央苏区后踏入的第一个省份。1934年10月25日至11月14日，中央红军长征主力部队转战广东韶关南雄、仁化、乐昌等地。在粤北群山间，广大红军指战员英勇奋战、不怕牺牲，成功突破国民党设置的多道封锁线，打开了向西挺进的关键通道。如今的粤北山区正持续融入粤港澳大湾区发展，奋力谱写高质量发展新篇章。

1934年10月，中央红军主力穿越南岭进入粤北。前方是粤湘桂等地军阀布下的多道封锁线，身后是步步紧逼的敌军。

这里是韶关的新田村，当年红军长征入粤的第一战就发生在这里。胜利之后，红军在这个村庄进行了短暂的休整。他们恪守纪律，不拿群众一针一线。

韶关南雄市史志办公室主任黄树材介绍称，当时红军战士住满了这些街道巷道，老百姓也是拥戴爱戴红军的，所以把红军战士请到祠堂里入住，晚上比较寒冷，所以老百姓也拆出些门板，铺上稻草，带上棉被，给这些红军战士驱寒。

休整之余，红军通过标语、歌曲等形式传播革命思想。在上朔村徐氏祠堂大门左侧的墙壁上，还保留着当时红军写下的歌曲。

黄树材介绍称，当时红军指战员写下这首《当红军歌》，其实也写出了老百姓的心声，当兵就要当红军，当年穷苦老百姓相信共产党，相信红军，跟党走，跟红军走，这是老百姓的心声。通过传唱《当红军歌》，上朔这一带，包括整个南雄这一带，有很多青年受到这首歌的感召后加入到红军的队伍中去。

红军离开之后，村民们用黄泥和稻草秸秆混合，把写着歌词的墙面糊住，躲过反动派的搜查。92年过去了，这首《当红军歌》依然字迹清晰，并且传唱至今。

南雄市油山镇大塘中心小学六年级学生欧欣蓉称：“歌声里承载着不怕艰难、顽强拼搏、团结奋进的伟大长征精神。作为新时代少年，我们通过传唱红歌，铭记革命历史，传承红色血脉。”

岁月流转，粤北大地对长征精神的传承从未停歇。如今，长征国家文化公园（广东段）建设沿途铺展，长征历史步道、铜鼓岭烈士纪念碑、红军长征临时指挥所旧址……一处处红色遗迹串珠成线，成为人们追寻红色足迹、汲取奋进力量的精神家园。

韶关南雄市文广旅体局局长钟筱蓉表示，他们坚持“修旧如旧、活化利用”原则，推进长征国家文化公园南雄段建设，修缮革命遗址并布展开放红色景点，串点成线、连线成片，红色文旅已经成为南雄经济增长的新引擎。

五岭逶迤，见证红军坚定的脚步。而今，90多年过去，他们曾艰难跨过的千山万水变得通达、宽阔。

从韶关高铁站出发，通过京广高速铁路，最快46分钟就能抵达广州南站。老区韶关也已经融入了粤港澳大湾区“一小时生活圈”。

如今，韶关已建成“十高三铁两航”综合立体交通网，航线、高铁、高速、水运四通八达，而更加便捷的现代化集疏运体系还在加快构建。

前不久，北江航道扩能升级上延工程全线开工，一条连接粤北与珠三角的“水上黄金通道”正加速形成。

位于韶关市区的北江大桥1983年建成通车，通航净高只有不到5米，只能通行百吨级的船舶。而在它旁边，正在建设的新北江大桥，建成之后通航能力将达到千吨级船舶。而北江流经韶关市区这段水路，一共有7座这样的桥需要改建，预计在2029年全部改建完成后，广东最北端的韶关乐昌千吨级的船舶将能够直通粤港澳大湾区。

水上航道的提档升级，让韶关打通通江达海的水运大动脉。而陆空融合的新型交通基础设施，则持续拓展着韶关立体交通的新维度。

位于韶关新丰县的南方试验场，是国内首个“路空一体”智能网联综合性国家级测试基地，智能网联汽车和低空飞行器共用一座试验场，推动“车-机-网-空”一体化研发测试。自今年3月启用以来，已吸引十多家汽车、低空飞行器企业入驻，测试400多台次，试验里程超300万公里，试飞近2000架次。

记者来到了一个算力中心的机房，一进入这里，首先听到的是轰鸣声，这是服务器等设备正在全力输出算力的表现。通过专门搭建的运力网络，这里可以对粤港澳大湾区各个城市发出的AI指令实现毫秒级反馈，满足自动驾驶、远程医疗等低时延场景的需求。

今天的粤北山区敢闯敢试，不断开辟新的发展路径。作为粤港澳大湾区唯一的国家级数据中心集群承载地，韶关实现了对广州、深圳、香港等地毫秒级响应。目前，韶关签约落地的数据中心达到24个，上架算力超4.5万P，成为华南地区最大的智能算力集聚区。

“十五五”期间，韶关还将同步推动冶金、装备制造等传统产业提质升级，大力发展绿色工业、现代农业、文旅康养等绿色产业，构建现代化产业体系。

广东省韶关市发展改革局局长王友华表示，今年是长征胜利90周年，伟大的长征精神深深扎根在韶关这片革命老区。90年来，老区发生了翻天覆地的变化，群众的生活发生了质的飞跃。展望未来，韶关将以“十五五”规划为发展蓝图，全面融入粤港澳大湾区建设，走出一条生态优美、生活富足的绿色高质量发展之路，让革命老区焕发新的时代光彩。
